## 🌟 Proyecto destacado: Máquina de Galton

Simulación de 3,000 bolas con 12 decisiones aleatorias por bola, desarrollada en Python y visualizada con Matplotlib.

Permite explorar la distribución binomial y su aproximación a la campana de Gauss.
