# 🎮 Proyecto Final Mes 4 — Pokédex con Python

## 📌 Descripción del proyecto

Este proyecto consiste en desarrollar una Pokédex utilizando Python y la API pública de Pokémon (PokéAPI).

El programa permite buscar un Pokémon por su nombre, consultar sus características, visualizar su imagen y guardar la información obtenida en un archivo JSON.

Fue desarrollado como parte del **Mes 4 del curso Fundamentos de Python**, aplicando los conocimientos adquiridos durante las semanas anteriores.

## 🎯 Objetivo

Desarrollar una aplicación en Python capaz de consumir información de una API externa, procesar los datos recibidos y almacenarlos en archivos JSON.

## ⚙️ Funcionalidades

- Buscar Pokémon por nombre.
- Consultar información mediante PokéAPI.
- Mostrar número, nombre, peso y altura.
- Consultar tipos, habilidades y movimientos.
- Abrir la imagen del Pokémon en el navegador.
- Guardar la información en archivos JSON.
- Manejar errores cuando un Pokémon no existe.
- Permitir realizar varias consultas mediante un menú interactivo.

## 🛠️ Tecnologías utilizadas

| Tecnología | Función |

## 📚 Conceptos aplicados

**Variables:** almacenan información que utiliza el programa.

**Funciones (`def`):** organizan las instrucciones en bloques reutilizables.

**Condicionales (`if`, `elif`, `else`):** permiten tomar decisiones.

**Ciclos (`while`):** mantienen activo el menú para realizar varias consultas.

**Diccionarios:** organizan información mediante claves y valores.

**Listas:** almacenan conjuntos de datos, como los movimientos de un Pokémon.

**Manejo de excepciones (`try`, `except`):** permite controlar errores durante la ejecución.

**Solicitudes HTTP:** permiten obtener información desde servicios externos.

**Archivos JSON:** permiten guardar y compartir datos estructurados.
