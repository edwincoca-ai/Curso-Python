# Proyecto Final - Mes 2

##  Descripción

Este proyecto forma parte del curso de **Fundamentos de Python** y consiste en resolver dos retos utilizando estructuras de control, operadores y funciones.

---

## 🎯 Retos del proyecto

### 1️⃣ Validar la longitud de una palabra

El programa solicita una palabra al usuario y verifica su cantidad de letras.

- Si tiene menos de 4 letras, indica cuántas letras hacen falta.
- Si tiene entre 4 y 8 letras, indica que la palabra es correcta.
- Si tiene más de 8 letras, indica cuántas letras sobran.

---

### 2️⃣ Encontrar el cuadrante

El programa solicita las coordenadas `X` y `Y` de un punto y determina en qué cuadrante del plano cartesiano se encuentra.

- Cuadrante I → `X > 0` y `Y > 0`
- Cuadrante II → `X < 0` y `Y > 0`
- Cuadrante III → `X < 0` y `Y < 0`
- Cuadrante IV → `X > 0` y `Y < 0`

También verifica si alguna coordenada es igual a `0`, indicando que el punto se encuentra sobre uno de los ejes.
