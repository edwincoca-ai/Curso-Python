# Reto Python - Semana 5

## Calculadora de años

Programa desarrollado en Python como parte del Bootcamp de Python.

### Descripción

Este programa permite comparar un año actual con otro año introducido por el usuario y determinar si:

- Los años son iguales.
- Ya han transcurrido determinados años.
- Falta determinado número de años para llegar al año indicado.

### Tecnologías utilizadas

- Python 3
- Visual Studio Code
- GitHub

### Conceptos practicados

- Variables
- input()
- Conversión de datos con int()
- Condicionales if, elif y else
- Operadores de comparación
- Operadores aritméticos
- f-strings
